# 使用指南 · Lite Video Editor

前端仍是一个独立 HTML 文件，无框架、无 CDN、无构建步骤。支持视频、图片、音频、文字的动态多轨编辑、花字、透明贴纸、转场、工程恢复，以及百炼自动字幕 / AI 配音。本机 FFmpeg 桥接器使用 Node.js 内置模块，无需安装 npm 依赖。

## 启动

直接用浏览器打开 `index.html` 即可编辑和导出，无需 Node.js 或 FFmpeg。浏览器导出通过实时录制完成，需要让页面保持在前台，输出格式由浏览器决定。

需要更快导出时，安装 Node.js 18+、FFmpeg 和 ffprobe，双击 `启动视频工具.bat`，或在本目录运行 `npm start` 后访问 http://127.0.0.1:8787/ 。桥接器会调用本机 FFmpeg；可以通过 `FFMPEG_PATH` 指定其路径。**AI 语音功能也需要通过桥接器的网页地址访问**，不能在 `file://` 页面调用。

目录入口为 `index.html`。浏览器标签页使用荧光绿剪刀图标，SVG 已嵌入页面；同时提供 `favicon.svg`、多尺寸 `favicon.ico` 和 PNG 图标。桥接器的 `/` 与 `/index.html` 均返回该入口。

## 导入和轨道

- 一次选择多个视频、图片、音频，或直接拖入窗口。支持 MP4 / MOV / WebM / MKV 等视频，PNG / JPG / WebP / GIF / AVIF 等图片，MP3 / WAV / M4A / AAC / FLAC / OGG 等音频；具体预览解码能力由浏览器决定。
- 图片按静帧加入，默认显示 5 秒；可拖动右边缘延长，或在右侧修改出点。PNG 透明度保留，动图按导入时捕获的一帧处理。
- 新工程默认只有画面 V1。视频和图片进入当前选择的画面轨；导入音频或添加文字时，会按需创建对应轨道。
- 时间线工具栏的 `＋ 添加轨道` 菜单可以继续添加画面轨、音频轨和文字轨，没有固定条数上限。上方画面轨覆盖下方画面轨，文字显示在画面之上。
- 拖动片段可改变开始时间，并移动到同类轨道；拖动边缘可裁剪。播放头和其他片段的边缘会在接近时吸附。也可以在右侧填写开始时间、选择轨道和填写入点 / 出点。
- 片段可以同时播放，轨道之间保留各自的开始时间；删除或裁剪一段不会移动其他轨道上的内容。空白画面输出黑场。
- 每条视频和音频轨的 `M` 控制静音；圆点按钮停用整条轨道（停用后其画面、声音或文字均不参与预览和导出）。`×` 删除空轨道，仅要求保留至少一条画面轨；音频轨和文字轨可全部删除。
- 画面可设置缩放、水平 / 垂直偏移和不透明度，适合画中画和图片叠加；音频片段有独立音量、静音、淡入和淡出。
- 文字保留样式预设、字号、颜色、底色、描边、阴影、字距、九宫格定位和起止时间，并可选择文字轨道。

撤销 / 重做保留最近 60 个编辑状态，包括轨道增删、静音、转场、字幕导入和工程载入。

## 花字与贴纸

- 「花字」提供 **30 套**可编辑样式，按描边、甜美、立体、霓虹、渐变和文艺分类；可按名称 / 示例文字搜索。包含漫画描边、奶油气泡、冰蓝立体、双色错位、空心描边、宋体、运动斜体与重点划线等。
- 点击样片添加新文字，或拖到文字轨；选中已有文字后，点击卡片上的「套用」保留文字内容与起止时间。文字仍可修改内容、字号、颜色和位置。普通文字预设会清除花字的附加效果。
- 花字支持双层描边、渐变填充、立体厚度、硬投影、霓虹光晕、空心字、双色投影、斜体和下划线。播放器、浏览器录制和 FFmpeg 的文字 PNG 共用同一绘制逻辑。没有视频时也可以用花字创建工程并导出。
- 「贴纸」提供 **112 张**透明插画，分为日常灵感、表情互动、美食饮品、旅行出行、自然天气、工作学习和庆祝创作七类，每类 16 张；支持分类与关键词组合筛选。
- 点击贴纸加入上层画面轨，或拖到画面 / 指定画面轨；默认持续 4 秒，可在画面中拖动，在属性中调整缩放、透明度与时长。已有最高画面轨承载视频时，会创建更高的贴纸轨。
- 贴纸透明度保留，工程 / 草稿按内置素材编号恢复。原先 16 张的编号继续兼容。花字插入、样式套用与贴纸插入都可撤销。
- 编辑器内嵌一张压缩 WebP 图集并按需裁切，不依赖外部图片地址。分发 `index.html` 单个文件即可离线使用这批素材。
- `assets/stickers/png/` 提供 112 张 256×256 独立 PNG，`sticker-atlas-112.json` 包含裁切坐标与分类，开发脚本生成的 `sets/` 提供新增六类的分组图集。4096×2048 的透明 PNG 总图集可从编辑器面板下载，也会由开发脚本打包到 `stickers-112.zip`；目录里不重复保留 PNG/WebP 总图文件。打包脚本在内存中生成图集，直接写入 HTML 和 ZIP。

贴纸通过内置 image_gen 分批生成，随后按主体裁切、清理独立背景散点并统一留白。新增 96 张的完整提示词保存在 `assets/stickers/generation-prompts-112.json`，原先 16 张的提示词保留在 `generation-prompts.json`。`scripts/expand-sticker-library.py` 是开发期打包工具，编辑器运行时不需要 Python 或 Pillow。

## 去背景与叠加

选中视频或图片，在右侧「去背景 / 色度抠像」中选择绿幕、黑底或自选颜色，可调容差和边缘柔化。把播放头放到底片要叠加的位置，点击「叠加到播放头」即可移入上层轨道并对齐；也可手动安排各轨。去背景会透出下方轨道，最下方没有素材时显示黑场。

设置随工程保存，支持撤销、分割、复制；预览、浏览器录制及本机 FFmpeg 导出均使用这些设置。主体中与背景相近的颜色也会受影响。更新本机版后请重启桥接器；旧桥接器会提示更新，以免导出时丢失去背景效果。详见[剪辑操作](editing.md)。

## 转场与画幅

- 左侧素材库有独立的「转场」分类，提供叠化、左右擦拭和左右滑动。悬停卡片可看动态样片；拖到同一画面轨的两段交界处插入，也可选中片段后点卡片上的 `＋`，或直接点击交界的 `＋` 插入点。
- 时间线上显示紫色转场块。选中后在右侧更换效果、调整时长；拖动转场块右边缘也能调时长。「播放转场预览」使用真实素材，从交界前播放到交界后并自动停止；`Delete` 或「移除转场」恢复硬切，可撤销 / 重做。
- 转场让后一片段与前段重叠，同时设置声音淡入 / 淡出，只移动后一片段，其他轨道保持原位。时长最多为两段中较短片段的一半。拆开关联片段时会移除对应转场；工程和草稿保留转场关联。
- 片段属性中的「片头 / 片尾效果」保留独立入场、出场设置；这些效果也会在时间线上显示可选中的转场块。预览与 FFmpeg 导出均生效。
- 播放器上方可切换原画幅、16:9 横屏、9:16 竖屏、1:1 方形和 4:5 图文画布。素材保持比例完整放入画布，可在画面变换中放大或移动。

## 工程保存与草稿恢复

- 顶栏的保存按钮或 `Ctrl+S` 下载 `.lightcut.json` 工程；打开按钮载入工程。工程保留轨道、字幕、片段区间、转场、画面 / 声音参数、画幅与输出设置。
- 视频和音频保留文件引用，不打包进工程。支持 File System Access 的浏览器会在导入时记住授权文件，打开工程时尝试自动读取；需要再次授权时点击「授权读取」。文件引用仅保留在当前浏览器、当前网站的本地存储中，工程只记录引用编号及文件信息，不保存绝对路径。
- 找不到文件时可批量选择原始素材，或在对应行点击「选择替代」。替代文件允许改名或大小变化，但类型必须相同，时长必须覆盖工程使用的区间；不能解码、时长不足等原因会直接显示。全部关联后才能载入，关联期间不改动当前时间线，工程载入可撤销。
- 旧工程仍可打开。首次手动关联并重新保存后可记住授权；换浏览器、切换本地 / 在线地址、清理网站数据或移动原文件后，可能需要重新选择。不支持文件授权接口的浏览器仍可手动关联。
- 内置背景和工程内嵌的图片可以直接恢复。普通图片需要保留原文件；浏览器草稿只内嵌较小图片，大图需重新关联。
- 编辑后自动将草稿写入当前浏览器存储，刷新后显示恢复入口。草稿状态显示在底栏；存储空间不足时请显式保存工程文件。草稿不替代原始媒体备份。
- AI 配音可在试听区或素材卡片下载 WAV；跨会话恢复时选择该 WAV 关联。API Key 不写入工程或草稿。

## AI 语音与字幕

点击顶栏「✦ AI 语音」，在「百炼设置」填写 Key 并保存。Key 仅保留在本次桥接进程内存中，服务重启后重新填写；也可在启动前配置 `BAILIAN_API_KEY` / `DASHSCOPE_API_KEY` 环境变量。

接口地址使用占位符，以下模型名仅作适配示例，请按已开通的服务修改：

| 用途 | 默认模型 | 接口路径 |
| --- | --- | --- |
| 配音 TTS | `qwen-audio-3.1-tts-plus` | `/api/v1/services/audio/tts/SpeechSynthesizer` |
| 自动字幕 ASR | `qwen-audio-3.1-asr-flash` | `/api/v1/services/aigc/multimodal-generation/generation` |
| 口播润色 / 字幕校对 | `deepseek-v4.1-flash-1017` | `/compatible-mode/v1` |

请将占位域名 `your-bailian-endpoint.example` 替换为自己的服务地址，地址和模型均可修改。自动字幕的 ASR 模型需要在你的业务空间开通，并支持真实句级或词级时间戳；DeepSeek 文本模型用于润色与校对。

- **字幕识别**：选择时间线上的视频 / 音频片段，仅提取其裁剪区间内的音频，通过百炼识别真实时间戳。长音频分段处理。先校对字幕草稿，再加入新的文字轨；可调整时间线偏移、逐条文字和起止时间，或下载 SRT。
- **AI 配音**：输入文稿，设置音色、语速、语言和风格提示；长稿自动分段合成。结果可先试听、下载 WAV，再加入独立音频轨；开启时间戳时可同步加入字幕。
- **DeepSeek**：口播润色和字幕校对均先显示建议，明确采用后才修改草稿，不会自动改动时间线。
- **本地 SRT**：可以导入 SRT 文件、粘贴 SRT 或读取已有字幕轨。无 Key 也能编辑、加入字幕轨和导出 SRT。

剪辑与成片导出仍在本机完成。点击识别时，所选区间音频发送到百炼；配音发送输入文稿；润色 / 校对发送相应文字。云端调用按账户用量计费，可取消任务。Key 不写入 HTML、浏览器存储、工程文件或响应日志。

接口已完成本地模拟服务与真实 FFmpeg 的联调。仓库默认不包含有效服务地址或 Key。真实百炼鉴权、模型开通状态及实际音色效果，需要填入有效 Key 后验证。接口依据：[ASR HTTP 文档](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-http-api)、[TTS HTTP 文档](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)、[音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。

## 导出

顶栏「导出视频」打开设置窗口。所有素材已交给桥接器时，由本机 FFmpeg 合成：按片段开始时间铺设画面、按层级叠加视频 / 图片 / 文字，将视频原声和独立音轨混合为 AAC，输出 MP4 / H.264。

没有桥接器时，通过 Canvas 和 Web Audio 实时录制同样的多轨合成。录制需要让页面保持前台；浏览器不支持录 MP4 时回落为 WebM。浏览器无法解码的素材需要本机 FFmpeg 才能导出，且没有浏览器预览。仅导入音频时，仍输出带黑色画面的音视频文件。

## 快捷键

`Ctrl+O` 导入、`Ctrl+S` 保存工程、`Ctrl+E` 导出设置、`Space` 播放 / 暂停、`← / →` 逐帧、`S` 分割所选片段、`T` 添加文字、`Ctrl+D` 复制、`Delete` 删除、`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做。`?` 查看说明。输入文字时保留输入框原生快捷键（`Ctrl+S` 保存工程除外）。

## 桥接接口

`GET /ping` 检测服务；`POST /upload?name=` 上传视频 / 音频；`POST /overlay` 上传图片 / 文字 PNG；`POST /render` 创建任务；`GET /job/:id` 查进度；`GET /download/:id` 下载成片。

多轨请求使用 `timeline: true`，`clips` 中每段包含 `id, kind, in, out, start, layer, scale, ox, oy, opacity, volume, muted, fadeIn, fadeOut`，以及可选的 `transitionIn / transitionOut: {type, duration}`。`start` 为时间线开始秒数，`layer` 越大越靠上；`texts` 为文字图层 id 和起止时间；`duration` 可以保留时间线末尾空白。其他输出参数仍为 `width, height, fps, quality, name`。省略 `timeline` 的旧请求继续使用顺序拼接。

AI 使用同源接口：`GET /speech/config` 返回不含 Key 的配置；`POST /speech/config` 更新配置；`POST /speech/jobs` 创建识别 / 配音 / 文本任务；`GET /speech/jobs/:id` 读取状态；`POST /speech/jobs/:id/cancel` 取消；`GET /speech/audio/:id` 试听生成的 WAV，支持 Range。仅接受本机页面来源，单个桥接进程同时处理一个 AI 任务。
