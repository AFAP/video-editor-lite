# 剪辑操作指南

直接打开 `index.html` 可试用浏览器模式。若已经启动旧版桥接器，请先关闭原来的服务窗口，再双击 `启动视频工具.bat`，刷新页面，以加载波形、关键帧和去背景导出功能。

新工程默认仅有画面 V1；通过「＋ 添加轨道」手动添加，或在导入音频、添加文字时按需创建轨道。已保存的工程保留原有轨道。音频波形上下对称居中显示，文件名使用透明背景。

## 绿幕 / 黑底去背景

1. 导入底片，再导入带绿幕或黑底的视频。
2. 选中需要去背景的片段，展开右侧「去背景 / 色度抠像」，选择「绿幕」或「黑底」。也可自选要去除的颜色。
3. 把播放头放到底片要叠加的位置，点击「叠加到播放头」：片段移到上方画面轨并对齐播放头，原有分组中的音频也同步移动。可撤销。
4. 增大「容差」可去除更多相近颜色；用「柔边」调整边缘透明过渡，再按需调整缩放、位置和透明度。

视频和图片均支持，预览、浏览器录制和本机 FFmpeg 导出均生效；工程、草稿、分割和复制保留设置。主体中与背景相近的颜色也可能被去除，尤其是黑底素材中的黑色区域；这类素材可降低容差或更换要去除的颜色。输出的是叠加后的成片。

## 多选、分组和轨道锁

- 按住 Shift / Ctrl 点击多个片段，或在轨道空白处拖动框选；Ctrl+A 全选未锁定内容，Esc 清除选择。
- 多选后可整体移动、复制和删除。Ctrl+G 分组，Ctrl+Shift+G 取消分组，也可使用右侧按钮。
- 点击轨道名称旁的 `◇` 锁定，显示 `锁` 后禁止修改该轨内容；再次点击解锁。
- 分组跨轨移动时保留各片段之间的时间偏移，锁定内容保持原位。

## 波纹删除和清除空隙

- 选中片段后点「波纹删除」或按 Shift+Delete，会删除对应时间区间，并收拢所有未锁定轨道。跨越区间的声音和字幕会同步裁剪。
- 「清除空隙」只删除所有轨道都没有内容的空白区间。普通 Delete 保持原有行为，不收拢后续内容。
- 试用时可先锁定一条轨道，检查它保持原位；Ctrl+Z 可撤销整步。

## 波形与分离音频

- 导入视频或音频后自动生成真实波形。桥接器会流式解析长素材；纯浏览器模式对 64 MB、20 分钟以内的素材尝试离线音频解码，解码能力取决于浏览器。
- 选中视频，在右侧「声音」中点「分离视频原声」：原视频静音，原声进入独立音轨，两段自动分组。
- 可取消分组后单独编辑声音；「重新生成波形」可以在连接桥接器后重试。

## 字幕定位和批量样式

- 时间线工具栏「字幕」打开文字列表，可按轨道筛选、搜索、替换和修改文字；点击时间返回对应画面。
- 在右侧调整一条文字的样式，点「样式应用到本轨」或「样式应用到所选」，统一字号、颜色、位置和花字效果，保留内容及起止时间。

## 关键帧

1. 选中视频或图片，右侧展开「◆ 关键帧动画」。音频片段支持音量关键帧。
2. 将播放头放到起始位置，选择属性并点击「◆ 添加」。
3. 移动播放头，填写新数值并点击「◆ 添加」。两点之间采用线性过渡。
4. 点击下方关键帧按钮定位，可删除当前点或清除某个属性的动画。

支持缩放、水平位置、垂直位置、不透明度和音量；文字图层动画暂未加入。关键帧记录在素材时间上，裁剪、分割和移动片段后仍可延续，工程保存、草稿和撤销均保留。浏览器预览、实时录制和本机 FFmpeg 导出都使用这些动画。

可先做一个从 100% 到 150% 的缩放，分别预览、导出短片，再保存工程重新载入检查。
