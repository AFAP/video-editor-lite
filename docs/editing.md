# 剪辑操作指南

直接打开 `index.html` 可试用浏览器模式。若已经启动旧版桥接器，请先关闭原来的服务窗口，再双击 `启动视频工具.bat`，刷新页面，以加载波形、关键帧和去背景导出功能。

新工程默认仅有「轨道1」。导入文件只进入左侧素材库，点击素材上的「＋」加入当前兼容轨道的末尾，同一素材可重复添加。通过「＋ 添加轨道」手动新增，或在加入音频、添加文字时按需创建；新增轨道默认放在底部。

拖动轨道名称左侧的 `⠿` 调整上下顺序，插入位置会显示绿线；也可选中手柄后按 `Alt + ↑ / ↓`。画面按上下顺序叠加，排序支持撤销并随工程保存。视频和图片的「不透明度、缩放、水平、垂直」均可拖滑杆或手填数值，支持小数、关键帧和撤销；范围分别为 0%～100%、10%～300%、−50%～50%、−50%～50%。音频波形上下对称居中显示，文件名使用透明背景。

## 属性复制与粘贴

选中片段，在右侧点击「复制属性」，再多选目标片段并点击「粘贴属性…」。可分别勾选画面变换、不透明度、去背景、声音，以及是否携带这些属性的关键帧。片段的素材、轨道、时间与转场保留；锁定片段和不兼容属性会跳过，应用前显示数量，整批可一次撤销。

不携带关键帧时，所选属性会变为静态数值；携带时按目标片段开头对齐动画，较短片段保留裁剪边界的插值。未勾选属性的动画保留。

## 原位替换素材

选中片段，点击「替换素材…」，使用素材库中的另一文件，或「选择新文件」。默认保留入出点、时长、位置、画面参数、转场和关键帧，只替换当前片段；分离的音轨可单独替换。

替代视频较短时会禁用应用按钮。可以选择从替代素材开头使用并保持时长，或明确选择「从开头使用可用长度，后续位置不动」。缩短可能留下空隙，无法衔接的转场会移除；也可换一个更长的文件。取消不会改动工程，应用支持一次撤销。

## 数值、适配与图片动效

画面、声音、文字和抠像滑杆旁均可输入数值，支持小数；点击 `↺` 重置单项。重置带关键帧的画面属性或音量时，会同时清除该属性的动画；其他属性保留。

「画面变换」可选完整显示或铺满裁切，输入 −180°～180° 旋转角度，或点击左右旋转 90°、水平翻转和垂直翻转。「重置画面」恢复完整显示及默认变换。

图片支持缓慢推近、拉远、上下左右平移。可多选图片后应用，按各自片段时长生成缩放与位置关键帧，采用铺满画布，保留不透明度、音量和其他设置。可继续编辑关键帧，或选择清除缩放 / 位置动效。上述设置在预览、浏览器录制和本机 FFmpeg 导出中生效，并随工程保存。

## 绿幕 / 黑底去背景

1. 导入底片和带绿幕或黑底的视频，分别点击素材卡片上的「＋」加入轨道。
2. 选中需要去背景的片段，展开右侧「去背景 / 色度抠像」，选择「绿幕」或「黑底」。也可自选要去除的颜色。
3. 把播放头放到底片要叠加的位置，点击「叠加到播放头」：片段移到上方画面轨并对齐播放头，原有分组中的音频也同步移动。可撤销。
4. 增大「容差」可去除更多相近颜色；用「柔边」调整边缘透明过渡，再按需调整缩放、位置和透明度。

视频和图片均支持，预览、浏览器录制和本机 FFmpeg 导出均生效；工程、草稿、分割和复制保留设置。主体中与背景相近的颜色也可能被去除，尤其是黑底素材中的黑色区域；这类素材可降低容差或更换要去除的颜色。输出的是叠加后的成片。

## 多选、分组和轨道锁

- 按住 Shift / Ctrl 点击多个片段，或在轨道空白处拖动框选；Ctrl+A 全选未锁定内容，Esc 清除选择。
- 多选后可整体移动、复制和删除。Ctrl+G 分组，Ctrl+Shift+G 取消分组，也可使用右侧按钮。
- 选中视频、图片、音频或文字后，`Ctrl+C` 复制，移动播放头后按 `Ctrl+V` 粘贴。单轨内容可粘贴到当前同类型轨道，多轨选择保留轨道关系、时间间距和分组；画面参数、去背景及关键帧一并保留。`Ctrl+D` 或工具栏「复制」可在所选内容后快速创建副本。
- 点击轨道名称旁的 `◇` 锁定，显示 `锁` 后禁止修改该轨内容；再次点击解锁。
- 分组跨轨移动时保留各片段之间的时间偏移，锁定内容保持原位。

## 波纹删除和清除空隙

- 选中片段后点「波纹删除」或按 Shift+Delete，会删除对应时间区间，并收拢所有未锁定轨道。跨越区间的声音和字幕会同步裁剪。
- 「清除空隙」只删除所有轨道都没有内容的空白区间。普通 Delete 保持原有行为，不收拢后续内容。
- 试用时可先锁定一条轨道，检查它保持原位；Ctrl+Z 可撤销整步。

## 批量图片时长

时间线工具栏点击「图片时长」，选择所选图片、当前轨道或全部图片轨道。原时长留空表示不限，也可填入 `3`，将所有 3 秒图片改为 `4` 秒；之后可继续将 5 秒、6 秒改为 9 秒。

应用前会显示匹配数量和修改后的画面总时长。各轨后续片段自动顺延，保留原有空隙、转场类型及重叠；图片变短导致转场过长时，自动缩短转场。整批修改可一次撤销。贴纸不参与批改。

勾选同步配乐时，会调整从片头开始、结尾与原画面基本对齐的音频，需有足够的原始音频长度。其他轨道的字幕和片段保持原位；涉及锁定轨道或跨轨分组时会提示先解锁或解除分组。

## 波形与分离音频

- 导入视频或音频后自动生成真实波形。桥接器会流式解析长素材；纯浏览器模式对 64 MB、20 分钟以内的素材尝试离线音频解码，解码能力取决于浏览器。
- 选中视频，在右侧「声音」中点「分离视频原声」：原视频静音，原声进入独立音轨，两段自动分组。
- 可取消分组后单独编辑声音；「重新生成波形」可以在连接桥接器后重试。

## 人声避让

把人声与配乐放到不同轨道，选中配乐片段，在右侧「声音」点击「人声避让…」。选择配乐轨道并勾选一个或多个人声轨道，设置「配乐保留」百分比，查看曲线后点击应用。例如原配乐为 40%，避让保留 25%，人声期间实际音量约为 10%。

避让与原有音量、淡入淡出、音量关键帧相乘，不覆盖这些设置。提前压低、保持及恢复时长可调；有真实波形时按声音阈值忽略停顿，无波形的素材会提示暂按片段范围处理。请选择干净的人声轨，背景音乐或噪声也可能触发避让，不使用在线识别服务。

移动、裁剪、分割或静音人声片段，停用人声轨，或波形解析完成后，避让会自动更新。锁定配乐轨不能修改设置；锁定人声轨仍可作为避让参考。点击「关闭本轨避让」恢复原有音量行为，应用与关闭均可撤销，配置随工程保存。

纯浏览器预览和录制、本机 FFmpeg 导出均生效。使用旧桥接器时需先重启，以加载避让曲线支持。

## 素材使用位置

素材卡片显示「未使用」或「已用 N 次」，可在素材库按使用情况筛选。一次引用直接定位，多次引用展开位置列表，显示轨道、起止时间及静音、停用、锁定状态，点击对应行即可选择并定位片段。

同一素材重复加入、分割片段或分离视频音频，都会增加引用次数；停用轨道中的引用也计入。计数随删除、替换、撤销、重做和工程恢复自动更新。定位保留轨道原来的静音、停用和锁定状态。

## 自动花字字幕

选中带有人声的视频或音频，点击右侧「自动字幕…」；花字库也提供「用当前花字生成字幕」。在百炼设置中保存 ASR 接口、模型与 Key，选择标准字幕、任一花字，或使用当前选中文字的样式与位置，再点击识别。

默认识别后自动按句级 / 词级时间戳加入新字幕轨；取消「识别后自动加入字幕轨」可先检查草稿再加入。只识别片段入点至出点，时间戳自动对齐它在时间线上的位置。字幕需要 ASR 模型提供真实时间戳，只有纯文字的模型结果会提示无法对齐。

新字幕轨默认开启「联动本轨字幕的样式与位置」。调好其中一条的高度、水平居中、花字、字号、颜色、描边等，整轨字幕会同步，各句文字及起止时间保持独立。普通标题不参与联动；可以关闭联动单独调整，再打开时以当前字幕为准统一。联动、样式及位置均支持撤销和工程保存。

默认服务地址为 `http://127.0.0.1:60001/`。模型配置和 Key 保存在当前浏览器的网站 localStorage，重启服务后自动恢复，不随工程导出。端口变化后需在新地址保存一次；后续可直接复用。

## 字幕定位和批量样式

- 时间线工具栏「字幕」打开文字列表，可按轨道筛选、搜索、替换和修改文字；点击时间返回对应画面。
- 在右侧调整一条文字的样式，点「样式应用到本轨」或「样式应用到所选」，统一字号、颜色、位置和花字效果，保留内容及起止时间。

## 关键帧

1. 选中视频或图片，右侧展开「◆ 关键帧动画」。音频片段支持音量关键帧。
2. 将播放头放到起始位置，选择属性并点击「◆ 添加」。
3. 移动播放头，填写新数值并点击「◆ 添加」。两点之间采用线性过渡。
4. 点击下方关键帧按钮定位，可删除当前点或清除某个属性的动画。

支持缩放、水平位置、垂直位置、不透明度和音量；文字图层动画暂未加入。关键帧记录在素材时间上，裁剪、分割和移动片段后仍可延续，工程保存、草稿和撤销均保留。浏览器预览、实时录制和本机 FFmpeg 导出都使用这些动画。

可先做一个从 100% 到 150% 的缩放，分别预览、导出短片，再保存工程重新载入检查。

## 工程恢复与本机导出

打开工程时，默认允许跳过未使用且找不到的素材；时间线中引用的素材仍需关联。取消勾选后，须关联完整素材库再载入。

连接本机 FFmpeg 后，导出前会同步参与输出的素材；桥接器重启后会重新上传可读取的原文件。无法读取时会提示重新关联，不会悄悄切换为实时录制。原画幅依据画面素材计算，分离出来的音频不影响画布尺寸。

导出任务可取消。连接暂时中断会自动重试；如已断开或刷新页面，在导出窗口点击「恢复上次导出」继续等待或下载，即使尚未载入工程也可恢复。桥接器需保持运行；重新启动桥接器后，旧任务需重新导出。
